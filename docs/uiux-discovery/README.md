# Jarvis UI/UX discovery

Inspection snapshot from 1 October 2026. This report describes the frontend seen then; it does not prescribe a redesign. Code and line numbers may have moved.

- [Desk map](desk-map.md): inspected routes, content, navigation.
- [Shared UI](shared-ui.md): controls, approvals, interactions.
- [Observations and questions](constraints-and-questions.md): usability hypotheses and functional requirements.

Code references identify evidence. Observations are interpretations, not verified usability findings. Confirm behavior in the running app.

The inspected app mounted JarvisRoot around routes, with a landing first frame and Desk on the main page. Separate routes included /masterdata, /canvas, and /lab/diarize. The main desk presented Monitor, Casual, and Engineering.

These findings remain a snapshot while evaluating the [recent specification](../../work/references/jarvis-ui-phase-1/SPECIFICATION.md). Component organization does not fix the future design.
