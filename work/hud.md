# HUD and voice

Wake: **Jarvis** / **Hey Jarvis** (and the prefs name). Name only → “Yes?” then command listen. Orb click, Space, and typing also send.

Always-on wake (header **Mic always on** / **Mic off**) is stored in the browser. Off stops wake listening. Space and the orb still start command listen. Escape cancels command listen, not the wake preference.

TTS is separate (`voice_enabled` in preferences).

Hydration: home HUD loads client-only so password-manager attributes do not mismatch.
